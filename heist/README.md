# Новый канал: «Ограбления и аферы» (TikTok, русская аудитория, баннер ВПН)

## Решения пользователя (22.11)
- Тема: реальные ограбления и аферы, **только реальные события и реальные имена**.
- **Ролик до 1:30** вместе с баннером; **вся история в одном ролике** (без «ЧАСТИ 2»).
  История ≈ 80 с (≈180–200 слов), баннер 7,2 с строго посередине, ≥ 25% экрана (как в паучке).
- Рассказчик **за кадром, не показываем**; рассказ от третьего лица, в 2–3 местах обращение к зрителю на «ты».
  Голос один на весь канал, мужской, спокойный, низкий (пользователь подбирает сам).
- Картинки: пользователь генерирует в ChatGPT, мы оживляем (наезды/панорамы) и кладём сверху
  субтитры, таймер, «РИСК %», штампы «ПОЙМАН/УШЁЛ», вопрос в конце для комментариев.
- Стиль: **№2 «мульт-сериал»** — плоский 2D, толстый чёрный контур, яркие плоские цвета (пример в чате 22.11).
- Название канала — предложено «Почти ушли» (не утверждено).

## Структура ролика (80 с)
Хук 0–4 с → цель и защита → план по шагам (таймер, РИСК %) → день ограбления → поворот (ПОЙМАН/УШЁЛ) → вопрос зрителю.

## Описание стиля для ChatGPT (в каждый запрос)
Style: 2D flat cartoon illustration, adult animated TV series look, thick clean black outlines, bold flat colors,
simple cel shading, slightly exaggerated characters with big noses and expressive faces. Moody cinematic lighting,
dark navy and teal shadows with warm orange and red accents. Vertical 2:3 image. No text, no letters, no logos anywhere
in the image. Keep the top 15% and bottom 25% of the image calm and less detailed (space for captions).

Порядок: новый чат на историю → лист героя (анфас, профиль, 3 эмоции) → сцены «Same character … Scene: …».
Картинки 1.png … N.png по номерам сцен.
